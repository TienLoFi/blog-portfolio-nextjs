## Câu 1. Cấu Trúc Route Cơ Bản
```php
Route::get('/user', [UserController::class, 'index']);
````

Gửi request GET đến `/user`, gọi phương thức `index` trong `UserController`.

## Câu 12. So sánh: find vs findOrFail

* `find`: Trả về `null` nếu không tìm thấy.
* `findOrFail`: Nếu không tìm thấy sẽ tự động trả về lỗi 404.

## Câu 19. Soft Deletes (Xoá mềm)

### Trong Model:

```php
use Illuminate\Database\Eloquent\SoftDeletes;

class User extends Model {
    use SoftDeletes;
}
```

### Trong Migration:

```php
$table->softDeletes(); // thêm cột deleted_at
```

### Sử dụng:

```php
User::withTrashed()->get();     // lấy tất cả, kể cả đã xoá
User::onlyTrashed()->get();     // chỉ lấy bản ghi đã xoá
User::find($id)->restore();     // khôi phục
User::find($id)->forceDelete(); // xoá vĩnh viễn
```

## Câu 20. Eager Loading – Tránh N+1 Query

```php

```

Lấy user + các bài viết (posts) liên quan chỉ trong 1 truy vấn duy nhất.
